# UI language

Use English for all system-generated interface text, navigation, labels, buttons,
validation messages, notifications and default audit descriptions. This applies to
existing and future features. Match the existing Member2Go English terminology.
Preserve user-entered material names and other business data. Existing Chinese
spreadsheet headers and unit aliases may remain supported as import compatibility;
they must not become interface labels. Do not translate or rewrite stored records
as part of a UI language change.
